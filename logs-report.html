Отчет по наблюдаемости: анализ логов веб-сервера

1. Теория: три столпа наблюдаемости

Логи (Logs) — это текстовые записи всех событий, происходящих в системе (кто зашел, что запросил, с каким результатом). Метрики (Metrics) — это числовые показатели за определенный период (например, загрузка процессора, количество запросов в секунду, температура сервера). Трассировка (Traces) — это путь одного конкретного запроса через все сервисы системы, который помогает найти узкое место или ошибку на любом этапе обработки.

3. Результаты анализа (таблица от ИИ)

Обнаружен подозрительный хост 192.168.1.105. В то время как другие IP (192.168.1.14, 192.168.1.45, 192.168.1.88) запрашивают легитимный контент, этот хост последовательно перебирает пути, характерные для поиска уязвимостей или попыток несанкционированного доступа.

Типы ошибок:

  • HTTP 403 (Forbidden) — возникает при POST-запросах к /admin/login.php. Это указывает на срабатывание механизма защиты от подбора пароля или блокировку по IP после нескольких неудачных попыток.
  • HTTP 404 (Not Found) — возникает при GET-запросах к /admin/config.php, /admin/access.php, /admin/.env. Злоумышленник ищет скрытые файлы конфигурации, которые отсутствуют на сервере.

4. Краткий вывод и рекомендации для администратора

Администратору необходимо немедленно заблокировать IP-адрес 192.168.1.105 в правилах файрвола. Также следует проверить журналы успешных входов, чтобы убедиться, что злоумышленник не получил доступ к панели администратора. В качестве превентивной меры рекомендуется включить автоматическую блокировку IP (rate limiting) после нескольких неудачных попыток входа и скрыть файлы окружения (.env) от прямого доступа извне.
